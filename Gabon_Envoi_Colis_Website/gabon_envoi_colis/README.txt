# Gabon Envoi Colis — prototype

Ouvrir `index.html` dans un navigateur.

Fonctionnalités incluses :
- accueil responsive avec thème gabonais
- services Chine / France / États-Unis
- catalogue avec panier
- formulaire de demande de devis
- sélection de l'origine depuis les cartes
- module de suivi de colis (démo)
- navigation mobile responsive
- boutons d'appel à l'action
- contact WhatsApp / email à remplacer par vos coordonnées réelles

À connecter avant production :
- base de données / espace client
- paiement réel (ex. Mobile Money selon les prestataires disponibles)
- API de suivi transporteur
- calculateur réel de fret et taxes/douanes
- authentification
- gestion des commandes et notifications
- coordonnées et politique commerciale réelles
